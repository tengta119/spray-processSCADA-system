# Modbus 地址映射

本表由原 S7 变量表按原顺序生成，名称、类型和保存标记保持原有含义。独立的 `PLC_Modbus_Config.xlsx` 供 Modbus TCP 模式使用。共 78 个变量：50 个线圈，28 个 32 位数值，占用 56 个保持寄存器。

地址均为从 0 开始的协议地址。Modbus Slave 使用 Slave ID 1，同时建立 Address 0、Quantity 50 的 01 Read Coils 窗口，以及 Address 0、Quantity 56 的 03 Read Holding Registers 窗口。若启用 PLC Addresses (Base 1)，第一个保持寄存器显示为 40001。参见 [官方地址说明](https://www.modbustools.com/mbslave-user-manual.html)。

## 线圈

## 手动输入示例

- 厂内温度 25 ℃：HR 16 = `0x41C8`（16840），HR 17 = `0x0000`。
- 厂内湿度 60%：HR 18 = `0x4270`（17008），HR 19 = `0x0000`。
- 水分炉温度 120 ℃：HR 12 = `0x42F0`（17136），HR 13 = `0x0000`。
- 固化炉温度 180 ℃：HR 14 = `0x4334`（17204），HR 15 = `0x0000`。
- 生产计数 100：HR 20 = `0x0000`，HR 21 = `0x0064`（100）。计数使用 Int32，不能按 Float 编码。

也可以在 Modbus Slave 为相应两寄存器选择 Float Big-endian 或 Signed integer Big-endian 格式后输入十进制数。Modbus 协议定义 16 位寄存器，跨寄存器的 32 位编码是本项目与模拟器约定。

原变量表中“精洗洗喷淋泵运行状态”的名称按原样保留，供已有界面绑定使用。
